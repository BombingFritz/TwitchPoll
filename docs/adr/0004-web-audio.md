# ADR: Web Audio für Ergebnis-Sound

## Status
Angenommen; Nutzer bestätigt

## Kontext
Gefordert ist ein kurzer Tadaaa-Sound zur Siegesanimation.

## Entscheidung
Bestehende Web-Audio-Synthese beibehalten, einmal je Poll-Ende.

## Verworfene Alternativen
Echte Audiodatei ist laut Nutzer nicht erforderlich.

## Konsequenzen
Keine Audio-Datei nötig; Autoplay-/AudioContext-Verhalten berücksichtigen.

# Entwürfe

Ablage für Design-Entwürfe zum Vergleich mit dem aktuellen `SpargelPoll.html`. Ansehen: `demo.html` öffnen und unter „Entwurf zum Vergleich“ den Pfad eintragen, z. B. `entwuerfe/SpargelPoll-b.html`. Ein Entwurf ist kein Release; OBS bindet weiter `SpargelPoll.html` ein. Ein Entwurf entsteht als Kopie von `SpargelPoll.html` und versteht dadurch `?demo=…`.

Prüfen mit derselben Testreihe: `WIDGET=entwuerfe/<Datei> npm test`.

Abgenommene Entwürfe wandern in `SpargelPoll.html` und werden hier entfernt; ihre Entscheidungen stehen dann in einem ADR.
